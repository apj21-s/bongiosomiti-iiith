# others/ — quarantine, not a bin

Nothing here is referenced by the running site. It is kept rather than deleted,
because "unreferenced today" and "finished with" are not the same thing, and a
file is easier to restore from a folder than to reconstruct from memory.

Each entry was checked with a whole-repo search across `.ts`, `.tsx`, `.css`,
`.js`, `.json` and `.md` before it moved, including the URL-escaped spellings
that image paths use (`music%20player.png`). Everything moved with `git mv`, so
history follows it and `git log --follow` still works.

**To restore something:** `git mv others/<path> <original location>`.

## scripts/

One-off asset preparation, run by hand and not part of any build. They sat at
the repository root, which is why they read as project files rather than as the
scratch work they are.

| File | What it did |
|---|---|
| `crop_pause.py`, `extract_pause.py` | Cut the pause button out of a larger source image. |
| `process_assets.py` | Batch-processed the player artwork. |
| `remove_bg.py` | Stripped backgrounds off asset images. |
